# 🔧 GestionQuincaillerie

Application desktop de gestion d'une quincaillerie : gestion des stocks, des ventes, des clients et des fournisseurs.

## 🛠️ Technologies utilisées

- **Langage** : Java 17+
- **Interface graphique** : JavaFX
- **Base de données** : MySQL (adapte selon ton projet)
- **IDE** : NetBeans

## ✨ Fonctionnalités principales

- Gestion des produits et suivi du stock
- Gestion des ventes et factures
- Gestion des clients et fournisseurs
- Tableaux de bord et statistiques
- Authentification des utilisateurs
